> Load End-of-Day (EOD) securities pricing data from **Amazon S3 Bronze storage into Snowflake RAW**, validate the load, and prepare metrics for downstream processing using Apache Airflow.

---

## 🎯 Objective

This module implements the **Snowflake loading stage** of the EOD securities pricing pipeline.

The process takes the EOD CSV file generated by the upstream ingestion process and loads it from the configured **Amazon S3 Bronze location** into Snowflake.

The Snowflake processing consists of three SQL steps:

- 📥 Copy EOD data from S3 into the RAW layer
- 🔍 Verify that the data was successfully loaded
- 📊 Calculate pre-merge metrics for downstream processing

The complete process is orchestrated by the Apache Airflow DAG:

```text
daily_eod_ingestion_dag.py
````

# 🔗 Snowflake Task Dependencies

The three Snowflake SQL operations execute sequentially:

```text
s01_copy_to_raw
        │
        ▼
s02_check_eod_prices_exist
        │
        ▼
s03_compute_premerge_metrics
```

This dependency ensures that:

1. 📥 Data is loaded before validation.
2. 🔍 Data is validated before metrics are calculated.
3. 📊 Metrics are calculated only after successful validation.

# 🛡️ Best Practices

### 🔐 Secure Connections

Use Airflow Connections for Snowflake credentials instead of storing credentials directly inside DAG files.

```text
snowflake_default
```

---

### 📦 Separate SQL from DAG Logic

Keep SQL transformations in dedicated `.sql` files rather than embedding large SQL statements directly inside Python DAG code.

```text
airflow/
└── dags/
    ├── daily_eod_ingestion_dag.py
    │
    └── sql/
        ├── 1. copy_to_raw.sql
        ├── 2. check_loaded.sql
        └── 3. premerge_metrics.sql
```

This makes the pipeline:

* Easier to maintain
* Easier to test
* Easier to review
* Easier to reuse

---

### 🔗 Maintain Task Dependencies

The Snowflake tasks should execute in the correct order:

```text
COPY
 │
 ▼
CHECK
 │
 ▼
METRICS
```

This prevents downstream processing from running against incomplete or missing data.
